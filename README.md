# 品詞ジェネレーター

日本語の文章を形態素解析し、単語を `[名詞]` `[助詞]` `[動詞]` などの品詞タグに変換するブラウザアプリです。

## 使い方

1. `index.html` をブラウザで開きます（初回はインターネット接続が必要です）。
2. 文章を入力して「品詞に変換」を押します。
3. 結果を「コピー」からコピーできます。

## 技術

- HTML / CSS / JavaScript
- [Kuromoji.js](https://github.com/takuyaa/kuromoji.js) による日本語形態素解析
- 辞書データは jsDelivr CDN から読み込みます。

## 注意

解析は形態素解析エンジンの判定に基づくため、文脈や固有名詞などによって品詞が期待と異なる場合があります。初回起動時は CDN からスクリプトと辞書を取得するため、インターネット接続が必要です。
